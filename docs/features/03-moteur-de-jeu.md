# 03 · Moteur de jeu (règles Hitster de base)

Statut : À faire

Logique pure côté serveur, indépendante du mode local ou en ligne.

- [ ] Modèle d'état : joueurs (nom, avatar), frise de chacun, titre en cours, tour actif
- [ ] Notion de tour de plateau (tous les joueurs ont joué une fois) et événement de fin de tour pour le récapitulatif des frises
- [ ] Tirage d'un titre dans les catégories choisies, sans répétition
- [ ] Placement d'une carte dans la frise et validation (les années égales sont acceptées)
- [ ] Gain de la carte si le placement est bon, défausse sinon
- [ ] Carte de départ pour chaque joueur
- [ ] Condition de victoire (nombre de cartes à atteindre, à confirmer : 10 dans Hitster)
- [ ] Tests unitaires des règles
